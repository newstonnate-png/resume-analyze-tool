# Triage Labels

The skills speak in terms of five canonical triage state roles. This file maps those roles to ordinary GitHub-style labels used in this repo's issue tracker.

Category labels remain the normal GitHub labels `bug` and `enhancement`.

| Matt Pocock state role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `triage` | Needs initial maintainer review |
| `needs-info` | `needs info` | More information is required |
| `ready-for-agent` | `help wanted` | Fully specified and ready to be picked up |
| `ready-for-human` | `needs review` | Requires direct maintainer judgment or review |
| `wontfix` | `wontfix` | Will not be actioned |

The state labels are deliberately ordinary project-management language. Do not expose internal agent workflow terminology in public issue labels.

When a skill refers to a canonical triage role, use the corresponding GitHub label from this table. A triaged issue should carry one category label and one state label.
