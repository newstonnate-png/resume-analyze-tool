# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to ordinary GitHub-style labels used in this repo's issue tracker.

| Matt Pocock role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `triage` | Needs initial review |
| `needs-info` | `question` | More information is required |
| `ready-for-agent` | `help wanted` | Ready to be picked up |
| `ready-for-human` | `enhancement` | Requires deliberate implementation/review |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical triage role, use the corresponding GitHub label from this table.
